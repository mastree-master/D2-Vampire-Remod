# D2S Remod

D2 Survivors 를 바탕으로 한 팬 리모드입니다. 원작 게임·D2S-MyPatch 와 따로 설치되고, 따로 세이브·따로 실행됩니다.

- 리모드 전용 유니크·세트·룬워드, 재료 탭, 호라드릭 큐브, 숙제·업적·칭호
- 멀티플레이(대기실·파티 전투·길드·채팅), 보스 탑(버티기)·순위
- 업데이트 기록: [CHANGELOG.md](CHANGELOG.md)

게임 파일(원작 실행 파일·그림·데이터)은 이 저장소에 없습니다. 설치 프로그램이 사용자 PC 의 원작 게임을 복사해 리모드를 입힙니다.

비공식 팬 프로젝트이며 Blizzard Entertainment 및 D2 Survivors 제작자와 무관합니다.
