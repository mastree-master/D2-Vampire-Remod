# D2 Vampire Remod

## 설치

**[D2-Vampire-Remod.bat 받기](https://github.com/mastree-master/D2-Vampire-Remod/releases/latest/download/D2-Vampire-Remod.bat)** → 받은 파일을 더블클릭하면 설치 창이 뜹니다.

디아블로 2 레저렉션이 설치된 PC 에서 실행하세요. 게임 안에서 새 버전이 나오면 [업데이트 하기]로 받습니다.

- 리모드 전용 유니크·세트·룬워드, 재료 탭, 호라드릭 큐브, 숙제·업적·칭호
- 멀티플레이(대기실·파티 전투·길드·채팅), 보스 탑(버티기)·순위
- 업데이트 기록: [CHANGELOG.md](CHANGELOG.md)
